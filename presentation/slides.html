Secret Leaks (Məxfi Açar Sızması)

Təcrübəsiz və ya tələsən proqramçılar OpenAI API key, AWS Token və ya DB şifrəsini koda yazıb GitHub-a push edirlər. Xakerlər botlarla GitHub-ı 2 saniyədə skan edib şirkəti qarət edir.

SAST Flaws (Kritik Kod Zəiflikləri)

SQL Injection və `eval()` kimi zəifliklər canlı serverə çatdıqda bütöv verilənlər bazası silinir və ya serverdə uzaqdan kod icra olunur (RCE).

🚨 Ənənəvi auditlər ayda 1 dəfə keçirilir. Bu müddətdə sistem artıq sındırılmış olur!

Core Engineering

Under the Hood (Core Engineering)

01. AST & REGEX ENGINE

Custom Scanner Engine

Python AST və Regex ilə SQLi, eval RCE, OS injection və 8 fərqli açar formatını (AWS, OpenAI, RSA) aşkarlayır.

02. FINGERPRINT & DEDUP

Deduplication Engine

SHA-256(file+line+cwe) ilə eyni xətanı tutan fərqli alətlərin nəticələrini təmizləyir, təkrar xəbərdarlıqları süzür.

03. CVSS v3.1 SCORING

CVSS Risk Scoring

Weighted Max Risk alqoritmi ilə layihəyə 0.0 - 10.0 arası real risk dərəcəsi verir.

📂 scripts/security_scanner.py + scripts/vapt_normalizer.py + scripts/remediation_engine.py
Remediation & Rollback

Deterministic Remediation & Automated Rollback

✅ 1. Deterministic Git Diff (.patch)

Sistem sadəcə tövsiyə mətni çıxarmır; developer-in 1 saniyədə tətbiq edə biləcəyi hazır patch faylı generasiya edir:

git apply playbooks/patches/security_autofix.patch

↩️ 2. Automated Rollback Planı

Fix asılılıqları pozarsa, Playbook-da göstərilən əmrlə dərhal əvvəlki stabil commit-ə qayıdılır:

git checkout -- demo_vulnerabilities/vulnerable_sample.py
🛡️ Qayda: Zero Unverified Production Mutation (Yoxlanılmamış heç bir kod canlı production-a getmir).
